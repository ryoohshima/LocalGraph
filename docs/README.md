## 前提

- 個人開発者 1 名による開発・運用を前提とする。
- 実装は AI 活用を前提とし、開発工数よりも**販路確保**を制約条件として扱う。

## 主要な意思決定サマリ

1. **toC（個人向け家計簿）は対象外**とする。
2. **士業・税理士事務所（toB）1 業種に絞る**。マルチドメイン同時展開は行わない。
3. 「完全通信ゼロ」から**「通信はするが利用者データは送らない」**へ方針転換。
4. フリーミアムの区切りは **PC 台数ではなく「非商用/商用 × 機能制限」**。
5. 契約シート数は**申告制**とし、技術的強制はライセンスキー検証のみに留める。

判断の根拠は各ドキュメントに記載。
