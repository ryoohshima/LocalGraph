# 実装フェーズ

各フェーズの目的と完了条件のみを定義する。**進捗は GitHub Issue で追跡し、本ドキュメントには転記しない。**

## Phase 1: 基盤

ドメイン型・IndexedDB スキーマ・Worker 通信の土台を敷く。

- 完了条件: ダミーデータを Dexie に保存・読み出しでき、Worker と型付きメッセージを往復できる

## Phase 2: データ取り込み

CSV / Excel をブラウザに読み込み、列とその型を確定させる。

- 完了条件: Shift-JIS の銀行 CSV と `.xlsx` を投入し、ヘッダーと先頭 N 行が正しくプレビューされる

## Phase 3: 列マッピング

任意フォーマットのファイルを、集計可能な形へ利用者が対応付ける。

- 完了条件: 軸を割り当てて保存でき、同一フォーマットの再投入時にプリセットが自動適用される

## Phase 4: 集計と可視化

本製品の主機能。

- 完了条件: 期間・カテゴリで絞り込み、集計単位を切り替えながらグラフを閲覧できる

## Phase 5: ローカルデータ管理

継続利用に必要な保存・削除・持ち出し。

- 完了条件: データセットの一覧・削除、エクスポート / インポートが動作する

**ここまでで無料版として公開可能な状態になる。**

## Phase 6: 配布とセキュリティ

営業に必要な成果物を揃える。

- 本番 CSP のレスポンスヘッダー配信、PWA によるオフライン化
- ライセンス署名検証（[06-design.md](./06-design.md) §10）
- 「通信先一覧・送信内容保証書」の作成（[02-security-policy.md](./02-security-policy.md) §4）
- 完了条件: 情シスへ提出できる資料が揃い、ライセンスキーでエディションが切り替わる

## Phase 7: 有料機能

- 顧問先ごとのワークスペース切り替え
- 対前年比・期間比較
- PDF レポート出力
- 完了条件: [03-monetization.md](./03-monetization.md) §3.2 の有料機能が一通り動作する
